## 確認のしかた

自動検証では次のことは判定できません。必ず人の目で確認してください。

1. お題と正解の意味が合っているか
2. 正解以外にも当てはまる答えが作れてしまわないか（とくに漢字の組み合わせ）
3. ヒントが正解を直接言ってしまっていないか、逆に関係のない内容になっていないか
4. 解説の説明が事実として正しいか
5. 一般的な日本語話者が短時間で解ける水準か（専門知識が要らないか）
6. 不快感を与える表現が含まれていないか

確認して問題があれば、該当する `src/data/questions.*.json` を直してから
`npm run validate` と `npm run questions:list` を再実行してください。
